# 구현 보고서

## 구현된 기능

### 전역 및 컴포넌트 레이아웃

- **Next.js App Router의 RootLayout 및 StatisticsLayout 생성**  
  → 글로벌 헤더와 사이드바로 페이지 감싸기
- **CSS 모듈을 사용해 반응형 헤더 구현**  
  → 네비게이션 스타일링, 활성 항목 강조, 호버 효과
- **순수 CSS 모듈로 아코디언 사이드바 구현**  
  → 단일 SVG 화살표 회전, 섹션 토글, 활성 링크 스타일링

### 대시보드 페이지

고객 분석 대시보드를 위한 **4열 × 3행 CSS Grid 레이아웃** 설계:

- **1행 1–3열**: 방문 현황, 성별 분석, 국적 분석 파이 차트
- **1행 4열**: 유입 분석 바 차트
- **2행 1–2열**: 연령대 분석 퍼널 차트
- **2행 3–4열**: 방문 빈도 라인/바 차트
- **3행 1–4열**: 고객 유지율 위젯

→ `grid-template-columns`, `grid-row`, `grid-column` 등 CSS Grid 속성 사용 보장

### ECharts 연동 (데이터 기반 차트)

- **방문 현황**: `/visit-status` API → 초진 vs 재진 비율 파이 차트
- **성별 분포**: `/gender-distribution` API → 이름+비율 레이블 파이 차트
- **국적 분포**: `/nationality-distribution` API → 동적 도넛 차트
- **유입 분석**: `/visit-frequency` → 히스토그램 기반 바 차트
- **연령대 분석**: `/age-distribution` API → 퍼널 차트
- **방문 빈도**: `/visit-frequency` → 라인/바 차트
- **고객 유지율 위젯**: `/retention-rate` API → 세미-도넛 게이지 + 멀티 로우 통계

※ 모든 차트에서 **값이 0인 슬라이스 레이블 숨김**, **퍼센트 소수점 두 자리 반올림**

### 오류 처리 및 사용자 경험

- 각 차트 컴포넌트에 **로딩 및 오류 상태 구현**
- `useEffect`, `useState`, `useMemo` 훅 **일관적 사용으로 렌더링 오류 방지**

## 추가 개선 사항 및 시도
